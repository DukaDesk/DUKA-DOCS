# Dashboard (Overview)

Route: `/dashboard`

The Dashboard is your **morning screen**: today's money, today's work, and shortcuts.

## What you see

- **Today's summary** — sales total, order count, low-stock count, pending bookings.
- **Goal progress** — a progress bar toward your monthly target.
- **Recent activity** — newest orders, reviews, payouts.
- **Shortcuts** — jump to Reports, Products, Orders.

## Daily routine (5 minutes)

1. Check **sales vs yesterday** and **pending orders** (badge in the sidebar also shows the count).
2. Open anything marked **low stock** — restock from [Products & Inventory](./products-inventory.md).
3. Open **pending bookings / preparing orders** from [Orders](./orders.md).
4. If revenue dips, check [Analytics](./analytics.md) for the cause before running a promo.

:::tip Badges
The sidebar shows live badges for **Orders** and **Messages** so you never miss a sale or an unread chat.
:::
