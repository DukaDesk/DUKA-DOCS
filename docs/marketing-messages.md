# Marketing, Messages & Notifications

Routes: `/dashboard/marketing`, `/dashboard/messages`, `/dashboard/notifications`

## Marketing

- Create promos (e.g. `50% Off Lunch`, `BOGO`, `Free Delivery`) — these render in the customer app's promotion list.
- Keep title, subtitle, badge and image tight; expired promos should be archived.

## Messages

- Built-in chat with customers. Sidebar badge shows unread count.
- Reply fast — slow replies show up as complaints in Help & Support.

## Notifications (merchant side)

- Order events, low stock, payouts. Same data feeds the customer app's **Notifications** screen template.
- Act on alerts the same day; clear them so the list stays trustworthy.
