# App Builder — Overview

Routes: `/desk-design`, `/canvas-editor`

The App Builder lets you design the **customer-facing mobile app** without code: pages, sections, components, bottom tabs, splash screen — then publish.

## The three areas

1. **App sections (left)** — page content: sections → components → sub-elements (text, color, image). Select anything to edit it on the right.
2. **Canvas (center)** — phone preview. Click a section/component to select it.
3. **Properties / Elements (right)** — when browsing you see the **Elements gallery** (Layout, Screens, Tabs, Buttons…); otherwise you see **Properties** for the selection.

## Learn by doing

Follow these hands-on guides in order:

1. [Adding Components](./adding-components.md) — select a section, add a button, arrange it.
2. [Screens Gallery](./screens.md) — one-click starter pages (Dashboard, Orders, Booking…).
3. [Sections & Layout](./sections-layout.md) — rows, columns, carousels, nesting.
4. [Pages & Bottom Tabs](./pages-tabs.md) — add/rename/delete pages; add/link/delete tabs.
5. [Editing & Styling](./editing-styling.md) — General vs Styling, lists, icons, tap actions.
6. [Preview & Test](./preview.md) — check everything as a customer would.
7. [Publish](./publish.md) — ship it and verify in My App.

## Bottom bar: Pages + Nav

- **Pages** — switch, rename (double-click), duplicate, delete, add. Full guide: [Pages & Bottom Tabs](./pages-tabs.md).
- **Nav** — edit bottom navigation tabs: icon, label, linked page, order.

## Splash screen

Edited under **Page Content → Splash Screen**: background color/image, logo, duration, enabled flag. It shows on app entry and never gets a nav tab.

## Safe workflow

1. Pick or add a **Screen**.
2. Add and arrange **components**, edit their **props**.
3. **Preview** (`Ctrl+P`), then **Publish**.
4. Verify in [My App](../my-app.md).
