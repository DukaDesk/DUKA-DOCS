# Screens Gallery — 10 Publish-Ready Templates

Open the builder → **Elements → Structure → Screens**. Click any card to **create the screen, link it to bottom nav, and load it** — ready for Publish.

Each screen is **props-aware** (every block maps to editable component props) and **style-aware** (elegant light theme, consistent radius/typography). The gallery shows a phone mock, description, block count and a `PUBLISH-READY` badge.

## 1. Dashboard

Shows a quick summary of key data, recent activity, and shortcuts.

- Hero greeting, Today's summary list, goal progress bar, Recent activity, View-reports button.
- Edit: hero title/subtitle, list items, progress value, button label.

## 2. Login & Sign-Up

Lets users securely access accounts with email or social logins.

- Centered welcome copy, email + password fields, Remember-me, Sign In (filled) + Create Account (outline), OTP/Google/Apple hint.
- Edit: placeholders, hints, button actions to your auth flow.

## 3. Profile & Settings

Lets users update personal details, change passwords, and manage app preferences.

- Avatar + name/email, Full name + Phone fields, push/email toggles, Save + Change-password buttons.
- Edit: default values, toggle states and colors.

## 4. Notifications

Displays alerts, updates, and messages — newest first.

- Title + subtitle, notification list (order confirmed, low stock, payout), Mark-all-read button.
- Edit: notifications array (`title / message / time / icon / unread`).

## 5. Help & Support

FAQs, contact form, and live-chat entry.

- Title, FAQ search bar, FAQ list, support card with live-chat button, Send-us-a-message form.
- Edit: FAQ items, card copy, form title.

## 6. Billing & Subscription

Manages payment methods, invoices, and active pricing plans.

- Plan card (e.g. Pro ₦9,800/mo), usage bar, payment-method list, invoices list, Update-payment button.
- Edit: plan name/price, progress value, invoice rows.

## 7. Analytics & Reports

Charts, metrics, sales data, and performance graphs.

- Revenue hero, key-metrics list, monthly-goal bar, top-seller card, rating, Export button.
- Edit: metric values, goal %, top-seller details.

## 8. Inventory / Catalog

Lists goods, stock levels, and categories.

- Search bar, category pills, 2-column menu grid with stock badges, stock-alerts list, Add-product button.
- Edit: categories, grid items (`name / price / desc / emoji / badge`), alerts.

## 9. Transaction / Order History

Past purchases, receipts, and fulfillment statuses.

- Title, search, order-history block (`id / status / items / date / total`), Download-receipts button.
- Edit: orders array and `showStatus`.

## 10. Calendar & Scheduling

Bookings, meetings, and deadlines.

- Title, calendar strip (today → +30), available-times label, slot grid, booking summary, Confirm-booking button.
- Edit: date range, slot duration, service/total.

## Also included

- **Checkout / Sales / Home** starters and **Splash** (splash configures the app-entry logo screen, no nav tab).

:::tip After adding a screen
Select any block → edit in **Properties** → Preview (`Ctrl+P`) → **Publish**. Verify in [My App](../my-app.md).
:::
