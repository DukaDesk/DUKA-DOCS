# Integrations

Route: `/dashboard/integrations` (+ `/dashboard/integrations/:name`)

Connect payments, delivery, and third-party tools.

1. Open **Integrations**, pick a provider.
2. Open its detail page, paste API keys / configure options in the config panel.
3. Enable it and place a **test order** before going live.
4. Watch the integration state badge — misconfigured keys fail silently at checkout.

Never paste secret keys into the docs, chat, or screenshots.
