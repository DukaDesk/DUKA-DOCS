# DukaDesk Merchant — User Guide

This site explains **how to use the DukaDesk Merchant app** day to day: from signing up, to taking orders, managing stock, building your customer-facing mobile app, publishing it, and getting paid.

## Who is this for?

- **Shop owners / merchant owners** setting up their business
- **Managers and sales staff** running daily operations
- **Support / ops** helping merchants publish and troubleshoot

## How the Merchant app is organized

After login you land in the **Dashboard shell** (`/dashboard`). The sidebar groups everything:

| Area | Route | What you do there |
|---|---|---|
| Overview | `/dashboard` | Today's sales, orders, low stock, shortcuts |
| Compliance / KYC | `/compliance` | Verify your business before publishing |
| Desk Design + visual builder | `/desk-design`, `/canvas-editor` | Design screens, pick templates, publish |
| My App | `/my-app` | See what is live after publish |
| Products / Inventory / Customers | `/dashboard/products`, `/dashboard/inventory`, `/dashboard/customers` | Catalog + stock + people |
| Orders | `/dashboard/orders` | Confirm, prepare, fulfill, refund |
| Analytics | `/dashboard/analytics` | Revenue, top sellers, repeat rate |
| Messages / Marketing / Notifications | `/dashboard/messages`, `/dashboard/marketing`, `/dashboard/notifications` | Talk to customers, run promos |
| Billing / Team / Settings | `/dashboard/billing`, `/dashboard/team`, `/dashboard/settings` | Plan, staff roles, shop preferences |
| Integrations | `/dashboard/integrations` | Payments, delivery, third-party tools |
